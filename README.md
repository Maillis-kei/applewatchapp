# 멍워치

애플워치와 아이폰에서 각각 다른 화면으로 열리는 강아지 웹 앱입니다. 개발자 계정·서버 없이 `index.html` 하나와 이미지 6장으로 동작합니다.

```
index.html      워치 모드 + 아이폰 컨트롤 타워 (전체 코드)
assets/*.jpg    강아지 6종 (시바·비숑·푸들·코기·허스키·리트리버)
```

## 1. GitHub Pages 배포

1. github.com 에서 새 저장소를 만듭니다 (예: `mung`, Public).
2. **Add file → Upload files** 로 `index.html` 과 `assets` 폴더를 그대로 올리고 Commit 합니다.
3. **Settings → Pages → Branch** 를 `main` / `/ (root)` 로 지정하고 Save 합니다.
4. 1~2분 뒤 `https://<아이디>.github.io/mung/` 로 접속됩니다. (HTTPS 라서 센서 권한 요청이 가능합니다)

## 2. 아이폰 → 워치 연결

1. 아이폰 Safari 로 위 주소를 엽니다. 컨트롤 타워가 뜹니다.
2. 이름·견종·악세서리·민감도를 고르고 **워치용 링크 복사**를 누릅니다.
3. 단축어 앱 → 새 단축어 → **URL의 웹 페이지 보기** 동작을 추가하고 링크를 붙여넣습니다.
   `URL 열기` 동작은 워치에서 오류가 나므로 쓰지 않습니다.
4. 단축어 설정에서 **Apple Watch에 표시**를 켭니다.
5. 워치에서 단축어를 실행하고 **시작**을 누릅니다.
6. 단축어로 열리지 않으면 컨트롤 타워의 **메시지로 나에게 보내기**를 누르고, 워치 메시지 앱에서 링크를 탭합니다.

설정을 바꾸면 링크를 다시 복사해 단축어의 URL 을 교체하면 됩니다.

## 3. 워치에서 처음 확인할 것

링크 생성기에서 **센서 진단 표시**를 켜고 복사한 링크로 열면 화면 왼쪽 위에 상태가 나옵니다.

| 표시 | 의미 |
|---|---|
| `센서 on` (초록) | 기울임·흔들기 동작. 숫자 n 이 계속 올라갑니다 |
| `센서 none` (주황) | 워치 웹뷰가 센서를 주지 않음 → 터치 모드로 자동 전환 |
| `센서 denied` | 권한 거부. 페이지를 닫았다 다시 열어 허용 |

기울임 방향이 반대로 느껴지면 **기울임 방향 반대로**를 켜세요 (용두 방향에 따라 다릅니다).

## 4. 조작

| 동작 | 반응 |
|---|---|
| 기울이기 / 드래그 | 그쪽으로 굴러가고 벽에 튕김 |
| 흔들기 / 강아지 두 번 탭 | 점프 + "멍!", 계속하면 어지러움 |
| 강아지 탭 | 하트 |
| 빈 곳 길게 누르기 | 간식 |

## 5. URL 파라미터

`?mode=watch&name=초코&dog=shiba&acc=hat&sens=1.5`

| 이름 | 값 |
|---|---|
| `mode` | `watch` / `phone` (없으면 화면 너비 260px 이하를 워치로 판단) |
| `name` | 이름 (8자) |
| `dog` | `shiba` `bichon` `poodle` `corgi` `husky` `golden` |
| `acc` | `scarf` `hat` `ribbon` |
| `sens` | 0.5 ~ 3 |
| `act` | 열릴 때 할 행동: `treat` `ball` `sleep` |
| `top` | 위쪽 여백(px). 워치 주소창에 가려지지 않게 비워 두는 높이, 기본 0 |
| `bar=1` | 주소창 밀어내기(실험): 페이지를 스크롤시켜 주소창이 접히는지 시도 |
| `flip=1` | 기울임 방향 반전 |
| `debug=1` | 센서 진단 표시 |

## 6. 실시간 동기화 (선택)

지금은 설정이 링크에 담겨 전달되므로, 아이폰의 케어 버튼은 아이폰 미리보기 강아지에만 반응하고 활동량도 기기별로 따로 셉니다. 아이폰에서 누른 간식이 워치에 바로 나타나게 하려면 `index.html` 의 `SYNC` 주석 영역에 있는 Firebase 스니펫을 연결하세요.
