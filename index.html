워치에 연결하는 방법
  1. 위에서 강아지를 꾸미고 워치용 링크 복사를 누릅니다.
  2. 아이폰 단축어 앱 → 새 단축어 → 동작 추가에서 URL의 웹 페이지 보기를 고르고 링크를 붙여넣습니다. (URL 열기는 워치에서 오류가 납니다)
  3. 단축어 설정(ⓘ)에서 Apple Watch에 표시를 켭니다.
  4. 워치의 단축어 앱에서 실행 → 시작을 누릅니다.
  5. 단축어로 안 열리면 메시지로 나에게 보내기 후 워치 메시지 앱에서 링크를 탭하세요.
